# ASM

Internal Vision 360 utilities.

## Diamond Utility

Desktop-style local diamond data processor. Related folders such as `260602-362-1` and `260602-362-RG` are grouped under the base name `260602-362`. Get MP4 copies selected variant videos into one output folder, renamed to the source folder name.

Windows EXE: wait for the **windows-exe** job on https://github.com/Support08-cloud/ASM/actions then download the **DiamondUtility-win-x64** artifact.

```bash
cd diamond-utility
npm install
npm run dev
```
