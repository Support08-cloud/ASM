# ASM

Internal Vision 360 utilities.

## Diamond Utility

Desktop-style local diamond data processor (scan → select → Get MP4).

Windows EXE: wait for the **windows-exe** job on https://github.com/Support08-cloud/ASM/actions then download the **DiamondUtility-win-x64** artifact.

```bash
cd diamond-utility
npm install
npm run dev
```
